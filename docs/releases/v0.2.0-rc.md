# v0.2.0 — Dossier | Release candidate

**Status:** Release candidate; **not yet tagged or published**. The latest published release is v0.1.0. Complete final checks before creating Git tag `v0.2.0` and the GitHub release.

## Release summary

The Continental now has a local Dossier workspace for saving job postings as immutable source documents, organizing opportunity fields and required/preferred qualifications, and inspecting where saved information came from. The optional AI workflow proposes grounded structured data, asks for specific permission before external processing, and permits only explicit, selective owner approval before a write.

New owner-approved metadata/technology values can retain durable verbatim excerpts and source fingerprints. Requirement records retain their own excerpts. Existing manual data and prior un-attributed records are not retroactively certified or labeled as verified.

## Included

- Source-preserving Opportunity Registry and browser Dossier workspace with create/edit/search/delete and required/preferred requirement management
- Explicit opt-in AI extraction preview via the configurable OpenAI Responses API adapter, disabled by default
- Strict schema and original-text excerpt validation, source fingerprint checks, and preview-only results
- Review, corrections, explicit confirmation and selective, transactional approval that preserves manually entered fields
- Durable metadata/technology citations, stale citation cleanup and visible citation panel
- Offline full-API preview → approval → reopen regression tests using a simulated provider, plus frontend provenance tests
- Two additive database migrations for Opportunity/Requirement records and source attribution (current head: `d39b2a4f7c61`)

## Explicit limitations

- Local-only, single-user, unauthenticated development build. **Do not expose the API or database publicly with personal records.** No tenant isolation or production-grade authentication.
- The OpenAI provider is disabled by default. API access/billing is separate from a ChatGPT subscription. Never commit `.env`, credentials, screenshots with personal details or database dumps. An explicitly approved posting will be transmitted to the configured external provider.
- Model/provider identity and extraction lifecycle status are not finalized. A displayed owner-approved citation is source linkage, not employer verification or model accuracy certification.
- No job-evidence match scoring, automatic job fetching, resume writing or applications are claimed for v0.2.
- Browser acceptance is limited to local fictional records; the offline integration suite uses a simulated provider and disposable tests.

## User-facing release description

**The Continental v0.2.0 — Dossier** adds a source-preserving job opportunity workspace with optional source-grounded AI extraction, deliberate user review and selective approval. Approved information can retain inspectable source citations, while original postings and manual career records remain under the owner's control. The feature is designed for local development and is not a publicly hosted service; live external AI integration is not independently verified unless explicitly stated in the release validation results.
